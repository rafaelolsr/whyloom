## Context

The research MVP proved the graph retrieval loop but did not define failure
behavior, repository boundaries, installation checks, or a repeatable release
gate for real codebase pilots.

## Proposed learning

Treat production readiness as an explicit local reliability contract:

- reject configuration and record paths that escape the repository;
- abort indexing before graph mutation when canonical records are invalid;
- never create a missing index from a read command;
- honor configured discovery boundaries;
- expose a deterministic `doctor` command and versioned JSON envelope;
- use compact context packets for agents while preserving cited evidence paths;
- verify the installed wheel in a clean repository, not only the source tree;
- report the Git baseline used by reflection and keep its output proposed.

## Alternatives

Adding hosted coordination, embeddings, or more language adapters was deferred.
Those features widen scope without first proving that the local trust and
release contract is dependable.

## Consequences

The CLI is suitable for controlled codebase pilots on Python repositories. A
public license and security contact remain owner decisions before publication.

## Evidence

- `tests/test_production_contract.py`
- `docs/PRODUCTION_READINESS.md`
- isolated wheel smoke test: `init → index → doctor → context --compact`
- self-hosted evaluation: 4/4 cases passed
